# 0002. 25% Token Advance with Jetty Balance Settlement

Instead of requiring 100% upfront payment, customers pay a 25% Token Advance online via Razorpay to confirm reservation intent, while settling the remaining 75% Jetty Balance directly with the boatman on arrival. This minimizes payment drop-off in the domestic tourist market, eliminates high refund liability for weather delays, and ensures immediate cash-in-hand for local boatmen.
